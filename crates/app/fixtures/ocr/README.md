# OCR Fixtures

These fixtures exercise the native macOS OCR worker path.

- `image-only-native-ocr.pdf` is a one-page image-only PDF. It was generated by rendering `GFM OCR NATIVE NEEDLE 8472` into an AppKit bitmap and embedding that bitmap into a CoreGraphics PDF page. The PDF intentionally contains no extractable text stream, so the production path must detect it as `image-only-pdf`, rasterize it with PDFKit, and recognize the raster with Vision.
